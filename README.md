# Analisis Penjualan Indomie di Warmindo (Jan-Agu 2022)

Analisis 499 transaksi penjualan: pembersihan data dengan Python,
segmentasi pelanggan, dan dashboard interaktif di Power BI.

## Masalah bisnis
Bagaimana mengoptimalkan strategi operasional dan penjualan Warmindo
melalui analisis perilaku konsumen dan efisiensi transaksi?

## Tools
Python (pandas, numpy), Power BI, Excel

## Alur kerja
1. Telaah dan validasi data mentah
2. Membuat Dim_Tanggal dan Dim_Pelanggan (segmentasi Loyal/Reguler/Sesekali)
3. Ekspor ke Dataset_Warmindo_Bersih.xlsx
4. Membangun dashboard Power BI

## Temuan utama
- Total penjualan Rp9,20 juta, 975 porsi, 99 pelanggan
- Mie kuah menyumbang 71% penjualan
- 16 pelanggan loyal menyumbang 27% penjualan
- Kamis adalah hari dengan penjualan terendah

## Isi repository
- Python_Dataset_Warmindo.ipynb: proses ETL dan segmentasi
